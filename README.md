## 🛠️ Tools

### Commercial & Web Tools
- **[Pika](https://pika.art/)** - Generative AI video creation tool that supports modifying specific regions or frames ("Modify Region").
- **[Runway Gen-1](https://research.runwayml.com/gen1)** - Video-to-video generation allowing style transfer via reference images.
- **[EbSynth](https://ebsynth.com/)** - A powerful tool for transferring the style of a painted keyframe to a video source using motion vectors.

---

## 🚀 Open Source Projects
- **[AnyV2V](https://github.com/Tiger-AI-Lab/AnyV2V)** - Official implementation of AnyV2V, a plug-and-play framework for video editing.
- **[ReVideo](https://github.com/MC-E/ReVideo)** - Code for ReVideo, enabling precise motion and content control in video editing.
- **[TokenFlow](https://github.com/omerbt/TokenFlow)** - Official implementation for consistent video editing using diffusion features.
- **[CoDeF](https://github.com/QiangZhou/CoDeF)** - Official implementation of Content Deformation Fields.
- **[FateZero](https://github.com/ChenyangQiQi/FateZero)** - Zero-shot text-based video editing codebase.
